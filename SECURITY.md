# Security Policy

## Supported Versions
Only the latest release (`v1.x`) is currently supported with security updates.

## Reporting a Vulnerability
If you discover a security vulnerability, please do NOT open a public GitHub issue.

Please report vulnerabilities privately by emailing the maintainer with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact and proof-of-concept (if available)

We will respond promptly and coordinate a patch release.
